## ¿Qué es la computación?

La computación es el conjunto de procesos que permiten manipular información mediante máquinas. En términos simples, es la ciencia que estudia cómo resolver problemas usando algoritmos y dispositivos electrónicos.

Hoy en día, la computación abarca desde el funcionamiento de un smartphone hasta los complejos sistemas que gestionan redes globales de datos. Pero para entender su presente, es necesario conocer su pasado.

### El ábaco: la primera herramienta de cálculo

El ábaco, inventado hace más de 2.0

    if len(arr) <= 1:
        return arr
    
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    
    return quicksort(left) + middle + quicksort(right)

# Example usage
arr = [3, 6, 8, 10, 1, 2, 1]
