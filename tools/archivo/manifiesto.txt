# Qué va al archivo y en qué orden. Lo lee tools/archivo/archivar.py.
#
# [N] Título            empieza la etapa N
# fuente | incluir | carpeta | estado | nota
#
# fuente:   hf:dueño/repo       repo de Hugging Face (se fija la revisión del momento de la descarga)
#           local:~/carpeta     algo que ya está en esta máquina (no necesita internet)
#           git:url-o-ruta      repositorio git, se guarda como un .bundle (git clone archivo.bundle lo recupera)
#           url:https://...     un archivo suelto (papers); en "incluir" va el nombre con que se guarda
# incluir:  patrones separados por coma, sobre la ruta del archivo en el repo ("*" = todo).
#           "!patrón" excluye (ej. !*Q6_K_L* para que *Q6_K* no traiga también el Q6_K_L).
#           De Hugging Face siempre se suman README.md y LICENSE* de la raíz.
# carpeta:  dónde queda dentro del archivo (una por línea, no se repiten)
# estado:   ok        nombre confirmado
#           verificar sacado de blogs o de memoria: `bajar` lo saltea hasta que se confirme con `tamanos`/`buscar`
#           y se cambie a ok (o se corre con --incluir-sin-verificar)
#
# Tamaños aproximados; `archivar.py tamanos N` da los reales.
